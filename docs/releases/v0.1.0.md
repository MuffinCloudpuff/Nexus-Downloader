# Nexus Downloader v0.1.0

首个 Windows x64 便携发行版，基于 Rust 下载服务、React 界面和 Tauri 托盘。
关闭界面进入托盘模式后销毁 WebView，下载仍由后台继续执行。

## 下载与使用

- `Nexus-Downloader-v0.1.0-windows-x64-portable.zip`：解压到可写目录，运行
  `Nexus Downloader.exe`。包含托盘、后台、FFmpeg / ffprobe 8.1 和 Deno 2.8.2。
- `Nexus-Downloader-v0.1.0-chromium-extension.zip`：扩展内部版本为 1.4.1，
  适用于 Chrome / Edge。解压后，在扩展管理页开启开发者模式，选择“加载已解压的扩展程序”，
  指向含 `manifest.json` 的目录。请保持托盘服务运行。
- `Nexus-Downloader-v0.1.0-source.zip`：本次发布的源码，包含固定版本的 Cat Catch
  子模块源码，不含旧 Ghost Python 应用。
- `SHA256SUMS.txt`：上述文件的 SHA-256 校验值。

需要 Windows x64 及 Microsoft Edge WebView2 Runtime。当前程序未进行代码签名。
升级前请退出旧版，保留自己的配置和任务数据；不要同时运行两份托盘。

## 本版内容

- 托盘、React 界面和扩展统一为 Nexus Downloader，任务由 Rust 后台统一管理。
- YouTube、哔哩哔哩、X 视频旁提供下载入口；实际可用性受网站、访问权限及网络影响。
- YouTube 使用受管理的 yt-dlp 提取信息，媒体传输由自己的 Rust 引擎完成。
  yt-dlp 首次使用时联网下载并校验，不包含任何用户缓存的工具或凭据。
- 修复 HLS 独立音轨处理，覆盖 X 等视频的音视频合并场景。
- 接管浏览器下载时保留浏览器提供的用户保存路径；支持图片分类和 Windows 文件类型图标。
- 仅在后台确认接管成功后清理该次浏览器下载记录，不删除其他浏览器下载记录。
- 媒体临时文件放在下载目标旁边；成功合并后清理，删除任务时同步清理。

## 数据与校验

发行包从空目录按白名单组装，不包含开发者的配置、配对令牌、下载记录、日志或下载文件。
运行后会在程序目录创建自己的 `config/`、`data/` 等目录，请勿将这些目录分享给别人。
扩展依赖本地托盘服务，不是独立下载器。

发布检查：后台与媒体回归测试 130 项通过、1 项可选联网测试跳过；桌面类型检查、图片分类
测试及生产构建通过；扩展类型检查、下载路径、接管记录、品牌测试及构建通过。
发行文件另行进行目录白名单、敏感内容和 SHA-256 校验。

第三方组件及其源码地址见包内 `THIRD_PARTY_NOTICES.md` 和 `licenses/`。
