# Nexus Downloader v0.1.1

Windows x64 修复更新：普通文件图标跟随 Windows 资源管理器，并更新浏览器下载接管逻辑。

## 本版修复

- 托盘打开的 React 界面直接读取 Windows 文件图标；已存在的文件优先使用自身图标，EXE 不再统一显示通用程序图标。
- 修复 NanaZip、Windows 照片等商店应用的间接图标资源解析；未下载完成的文件使用当前系统文件关联图标。
- X、YouTube、哔哩哔哩视频保留专用图标；普通文件不会仅因目录或文件名中含网站名称而被误判。
- 浏览器下载不再按文件格式白名单过滤；保留浏览器提供的用户保存位置。
- 接管采用确认、清理浏览器记录、启动下载的顺序，避免浏览器清理记录误删新下载文件。
- 浏览器已完成的 blob/data/file 等下载登记到统一任务列表，不伪装成 Rust 网络传输。
- 修复空文件下载和原生配对进程提前初始化下载服务的问题。

## 下载与升级

- `Nexus-Downloader-v0.1.1-windows-x64-portable.zip`：Windows x64 托盘和 Rust 后台，包含 FFmpeg / ffprobe 8.1、Deno 2.8.2。解压到可写目录后运行 `Nexus Downloader.exe`。
- `Nexus-Downloader-v0.1.1-chromium-extension.zip`：Chrome / Edge 扩展，内部版本 1.4.2。解压后在扩展管理页加载含 `manifest.json` 的目录；已有安装可替换对应扩展目录并刷新扩展。
- `Nexus-Downloader-v0.1.1-source.zip`：与本版对应的完整源码，包含固定版本 Cat Catch 子模块源码，不含旧 Ghost Python 应用。
- `SHA256SUMS.txt`：上述三个文件的 SHA-256 校验值。

升级前请从托盘退出旧版，只替换发行文件，保留自己的 `config/`、`data/`、`logs/`、`downloads/` 等运行目录。不要同时启动两份托盘。
需要 Microsoft Edge WebView2 Runtime；当前程序未签名。yt-dlp 在首次需要时联网获取并校验，网站下载受访问权限与网络影响。
