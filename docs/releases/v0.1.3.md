# Nexus Downloader v0.1.3

修复全新安装可能无法自动配对的问题。扩展内部版本为 1.4.4。

## 改进

- 配对令牌统一由常驻 Rust 后台生成、保存和验证，启动时初始化。浏览器桥接进程只向后台取令牌，不再生成或改写令牌文件。
- 后台未启动时扩展显示等待并持续自动重试；后台启动后自动连接，无需输入配对码或先打开 React 界面。
- 串行化首次令牌生成、撤销，避免多个客户端同时连接产生不同令牌；扩展合并并发连接，旧令牌失效后自动重新获取。
- 后台退出、重启以及扩展后台重新加载后自动恢复连接。
- 为 Chrome 和 Edge 显式注册本地桥接入口；第二份后台无法占用端口时不会覆盖正在运行的后台注册信息。
- 桥接仅访问本机回环地址，不经系统代理，不跟随重定向；限制本地消息大小，并对不可用的后台返回可重试状态。

## 下载与升级

- `Nexus-Downloader-v0.1.3-windows-x64-portable.zip`：托盘、Rust 后台及媒体工具。
- `Nexus-Downloader-v0.1.3-chromium-extension.zip`：Chrome / Edge 扩展 1.4.4。
- `Nexus-Downloader-v0.1.3-source.zip`：对应源码，含固定版本 Cat Catch 子模块，不含旧 Ghost Python 应用。
- `SHA256SUMS.txt`：三个 ZIP 的校验值。

从托盘退出旧版，替换发行文件，保留自己的 config、data 等运行目录。扩展也需更新，在浏览器扩展管理页点击重新加载。不要同时启动不同位置的多份程序。

发行包不包含个人配置、令牌、浏览器资料、下载记录或日志。需 Windows x64 和 WebView2 Runtime；程序尚未签名。第三方许可和源码来源随包提供。

## 回归测试

`tests/pairing_fresh_install.mjs` 使用空安装目录、真实 Rust 后台和真实 Native Messaging 子进程，配合实际扩展客户端验证：扩展先启动、后台先启动、并发配对、后台退出重启、令牌撤销、扩展后台重载、安装令牌重新生成。
测试适配浏览器 storage/native API 边界，不冒充浏览器扩展安装界面的自动化测试；测试后恢复本机 Chrome/Edge 注册入口。

本版验证：后台 144 项测试通过，1 项可选联网测试跳过；扩展类型检查及 8 组专项测试通过，包含定时重试和休眠唤醒后的连接恢复；桌面类型检查、图标测试及生产构建通过。空目录真实进程配对测试全部通过。
