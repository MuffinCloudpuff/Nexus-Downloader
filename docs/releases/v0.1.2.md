# Nexus Downloader v0.1.2

本版集中修复抖音慢连接恢复、视频悬浮按钮和抖音任务图标。

## 修复与改进

- 抖音媒体使用更短的分段与请求范围；连接长时间停滞或持续显著降速时，从已写入的位置重新连接，并限制连续无进展重试。此机制不能保证绕过网站限速或消除网络波动。
- 修复暂停后续传可能截断已下载数据的问题；暂停确认前等待旧传输退出，避免暂停、继续时两套传输争用同一文件。
- 下载中的悬浮按钮可暂停，暂停后可继续同一任务；合并阶段不提供无效的暂停操作。
- 保留 B站、YouTube 原有普通窗口位置逻辑。抖音大播放器采用全屏式自动隐藏与鼠标唤醒，但按钮锚定实际视频区域的右上角，不再跑到评论区；播放器缩放时立即跟随。
- 扩展重新加载时清理旧悬浮按钮和事件监听，避免新旧脚本叠出两个按钮，包括旧定时器重新挂载按钮的情况。
- 改善 B站自定义播放器、隐藏视频元素和嵌入播放器的按钮发现；仅有 AV 编号的嵌入页会提示打开原视频页，不伪装成解析成功。
- 托盘打开的 React 界面使用新的抖音专用图片；通过真实媒体来源识别抖音任务，兼容共用合并流程的旧任务，不再误用 B站图标。普通文件继续使用 Windows 文件图标。

## 下载与升级

- `Nexus-Downloader-v0.1.2-windows-x64-portable.zip`：Windows x64 托盘和 Rust 后台，包含 FFmpeg / ffprobe 8.1、Deno 2.8.2。
- `Nexus-Downloader-v0.1.2-chromium-extension.zip`：Chrome / Edge 扩展，内部版本 1.4.3。
- `Nexus-Downloader-v0.1.2-source.zip`：本版完整源码，含固定版本 Cat Catch 子模块，不含旧 Ghost Python 应用。
- `SHA256SUMS.txt`：三个 ZIP 的 SHA-256 校验值。

先从托盘退出旧版，再替换发行文件，保留自己的配置和任务目录；不要同时启动多份托盘。
扩展更新后在扩展管理页点击“重新加载”，再切回视频页。需要 Microsoft Edge WebView2 Runtime；程序尚未签名。
